# Web AI Chatbot

A high-quality ChatGPT-like web chatbot built using FastAPI and open-source LLMs.

## Features
- Streaming responses (typing effect)
- Conversation memory
- Clean dark UI
- Web-only application
- 100% free and open-source

## Tech Stack
- Python + FastAPI
- Ollama (LLaMA 3)
- HTML, CSS, JavaScript

## Setup Instructions

### 1. Install Ollama
https://ollama.com

```bash
ollama pull llama3
ollama serve
