# Web AI Chatbot

A high-quality ChatGPT-like web chatbot built using FastAPI and open-source LLMs.

## Features
- Streaming responses (typing effect)
- Conversation memory
- Clean dark UI
- 100% open-source
- No API cost

## Tech Stack
- Python + FastAPI
- Ollama (LLaMA 3)
- HTML/CSS/JavaScript

## Run Instructions

### 1. Install Ollama
https://ollama.com

```bash
ollama pull llama3
ollama serve
